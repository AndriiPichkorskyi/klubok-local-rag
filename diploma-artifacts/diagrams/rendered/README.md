# Повнорозмірні схеми

Тека містить повні версії схем у SVG і PNG. У друкованих додатках пояснювальної
записки чотири з них подані у спрощеному вигляді — через обмеження формату
сторінки; тут лежать повні.

| Файл | Додаток записки | Що на схемі | Друкована версія |
|---|---|---|---|
| `figure-A-1.svg` / `.png` | А | конвеєр індексації: сканування, витягування статей, чанкування, векторизація | спрощена |
| `figure-A-2.svg` / `.png` | Б | обробка запиту: гібридний пошук, RRF, формування контексту, генерація | спрощена |
| `figure-A-3.svg` / `.png` | В | контракт RPC між Tauri (Rust) і sidecar (Node.js) | та сама |
| `figure-A-4.svg` / `.png` | Г | адаптери операційних систем і реалізація для macOS | та сама |
| `figure-A-5.svg` / `.png` | Д | покрокове ведення: знімок екрана, аналіз, оверлей | спрощена |
| `figure-A-6.svg` / `.png` | Е | перша архітектурна ітерація обробки запиту | спрощена |

Друковані версії під іменами додатків лежать у `../for-thesis/`, вихідні
`.mmd` / `.mermaid` — у `../sources/`.

Для перегляду з масштабуванням беріть SVG: PNG зроблені для вставки в документ.
