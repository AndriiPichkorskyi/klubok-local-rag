# Програмно-апаратне середовище експериментів

Усі наведені в дипломній роботі вимірювання виконано на одній машині 02–03.09.2026.

| Параметр           | Значення                                            |
| ------------------ | --------------------------------------------------- |
| Комп'ютер          | Apple MacBook Air, чип Apple M3                     |
| Логічних CPU       | 8                                                   |
| Unified memory     | 16 GiB                                              |
| Операційна система | macOS 25.6.0                                        |
| Node.js            | 24.7.0                                              |
| Ollama             | 0.33.2                                              |
| Застосунок         | Klubok 0.1.0 (Tauri 2 + React 19 + Node.js sidecar) |

## Моделі

| Роль                                     | Моделі, що брали участь у вимірюваннях                                               |
| ---------------------------------------- | ------------------------------------------------------------------------------------ |
| chat                                     | `qwen3:1.7b`, `gemma3:1b`, `qwen3:0.6b`, `gemma3:270m`                               |
| embedding                                | `qwen3-embedding:4b`, `qwen3-embedding:0.6b`, `nomic-embed-text:latest` (v1.5, 137M) |
| vision (walkthrough, поза експериментом) | `qwen2.5vl:3b`                                                                       |

## Параметри прогонів

Факторний експеримент: 36 конфігурацій × 68 кейсів = 2448 запусків, `seed = 42`,
`temperature = 0.1`, chat `qwen3:1.7b`, embedding `qwen3-embedding:4b`.

Матриця моделей: 12 комбінацій × 68 кейсів × 3 значення seed.

Корпус на момент вимірювань: 129 програм, 2357 документів, 15 789 фрагментів;
кожна embedding-модель індексувала той самий корпус.

## Застереження

Результати отримано на одній машині, одному корпусі та одному наборі задач.
Відсотки не переносяться на інші комп'ютери, корпуси чи мови без повторних вимірювань.
GPU-показники у звітах є загальносистемними для macOS і не характеризують окрему модель.
