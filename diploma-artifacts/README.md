# Klubok — матеріали до дипломної роботи, v1.0.0

Матеріали для перевірки прототипу та відтворення результатів, наведених у пояснювальній
записці до дипломної роботи **«Розробка кросплатформної системи рекомендації локальних
програмних інструментів на основі аналізу наміру користувача»** (Андрій Пічкорський,
Neoversity, MSc Computer Science, вересень 2026).

Вимірювання виконані 02–03.09.2026 на одній машині Apple M3 / 16 GiB / macOS 25.6.0.
Умови й застереження — у `metadata/environment.md`.

## Що де лежить

| Тека | Вміст | Пов'язано із запискою |
|---|---|---|
| `config/` | `pipeline.config.json` — конфіг конвеєра на момент вимірювань | розділ 3.3, додаток Ж |
| `experiments/factor-matrix/` | первинний JSON факторного експерименту (36 конфігурацій, 2448 запусків) і CSV-підсумок | таблиці 4.4–4.5, додаток К |
| `experiments/model-matrix/` | 12 первинних JSON-звітів матриці моделей і CSV-підсумок | таблиці 4.6–4.7, додаток Л |
| `experiments/persistent-failures/` | сім тестових випадків зі сталим негативним результатом | додаток М |
| `test-set/` | тестовий набір (укр. і англ.), обидва прогони і висновки тестування | додаток И |
| `diagrams/sources/` | вихідні `.mmd` / `.mermaid` усіх схем | додатки А, Б, В, Г, Д, Е |
| `diagrams/rendered/` | повнорозмірні схеми: SVG і PNG | там само |
| `diagrams/for-thesis/` | ті самі схеми під іменами додатків записки | там само |
| `rpc/rpc.md` | повний контракт RPC між Tauri і Node.js sidecar | додаток В, скорочено — додаток Ж |
| `metadata/` | середовище, контрольні суми тестового набору, перелік файлів архіву | — |

## Як перевірити результати без запуску системи

Первинні JSON-звіти самодостатні: кожен містить фактичні назви моделей, осі прогону,
`seed`, параметри й результат кожного кейса. CSV-таблиці — це агреговані зрізи тих
самих звітів; агрегація перевіряється прямим перерахунком із JSON.

## Як запустити сам застосунок

Інсталяційний образ `Klubok-0.1.0-aarch64.dmg` прикріплений до того самого GitHub Release.
Вимоги: macOS 11+, **тільки Apple Silicon**, встановлена Ollama з моделями `qwen3:1.7b`
і `qwen3-embedding:0.6b`. Застосунок підписаний самопідписаним сертифікатом, тому після
завантаження потрібно зняти карантин:

```sh
xattr -dr com.apple.quarantine /Applications/Klubok.app
```

Порожня база знань будується самим застосунком (години) або розпаковується з архіву даних,
якщо він доданий до релізу.

## Ліцензія та цитування

Матеріали публікуються для перевірки дипломної роботи. Первинні дані отримані автором;
документація програм, що індексувалася, належить її правовласникам і в архів не входить.
