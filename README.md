# Klubok — локальний RAG-асистент для пошуку встановлених програм

Репозиторій супроводжує магістерську роботу **«Розробка кросплатформної системи
рекомендації локальних програмних інструментів на основі аналізу наміру
користувача»** (Андрій Пічкорський, Neoversity, MSc Computer Science, 2026).

**Klubok** — локальний помічник для macOS: за описом задачі природною мовою він
знаходить уже встановлену на комп'ютері програму і показує кроки з її довідки.
Пошук по документації і генерація відповіді виконуються локально через
[Ollama](https://ollama.com), запити користувача не покидають машину.

> **Статус.** Зараз опубліковані матеріали для перевірки результатів роботи,
> інсталяційний образ застосунку та ліцензії. Вихідний код прототипу буде
> відкритий у цьому ж репозиторії до 15 вересня 2026 року.

## Матеріали для перевірки

Тека [`diploma-artifacts/`](diploma-artifacts/) містить усе, що потрібно для
перевірки наведених у записці чисел без запуску системи:

| Тека | Вміст |
|---|---|
| `experiments/factor-matrix/` | первинний JSON факторного експерименту (36 конфігурацій, 2448 запусків) і CSV-підсумок |
| `experiments/model-matrix/` | 12 первинних звітів матриці моделей і CSV-підсумок |
| `experiments/persistent-failures/` | тестові випадки зі сталим негативним результатом |
| `test-set/` | тестовий набір (укр. і англ.), обидва прогони і висновки тестування |
| `diagrams/` | схеми конвеєра, обробки запиту, RPC, адаптерів і walkthrough: джерела `.mmd`, SVG і PNG |
| `config/` | `pipeline.config.json` на момент вимірювань |
| `rpc/` | повний контракт RPC між Rust- і Node-частинами |
| `metadata/` | середовище вимірювань, контрольні суми, перелік файлів |

Опис складу і зв'язок із додатками записки — у
[`diploma-artifacts/README.md`](diploma-artifacts/README.md).

Вимірювання виконані 02–03.09.2026 на одній машині: Apple M3 / 16 GiB /
macOS 25.6.0. Обсяг індексу — 129 програм, 15 789 фрагментів.

## Реліз

Файли прикріплені до релізу
[`diploma-artifacts-v1.0.0`](../../releases/tag/diploma-artifacts-v1.0.0):

| Файл | Що це |
|---|---|
| `Klubok-0.1.0-aarch64.dmg` | застосунок для macOS 11+, **лише Apple Silicon** |
| `klubok-data.tar.gz` | готова база знань (щоб не будувати індекс годинами) |
| `diploma-artifacts-v1.0.0.zip` | ті самі матеріали, що в теці `diploma-artifacts/`, одним архівом |
| `SHA256SUMS.txt` | контрольні суми файлів вище |

Вимоги до застосунку: macOS 11+ на Apple Silicon, встановлена Ollama з моделями
`qwen3:1.7b` і `qwen3-embedding:0.6b` (≈1,5 ГБ). Образ підписаний самопідписаним
сертифікатом без нотаризації Apple, тому після встановлення потрібно зняти
карантин:

```bash
xattr -dr com.apple.quarantine /Applications/Klubok.app
```

Готову базу знань розпакувати в теку даних застосунку:

```bash
mkdir -p "$HOME/Library/Application Support/com.andriipichkorskiy.local-tool-rag-assistant"
tar -xzf klubok-data.tar.gz -C "$HOME/Library/Application Support/com.andriipichkorskiy.local-tool-rag-assistant"
```

Крок не обов'язковий: без нього застосунок просканує програми, завантажить
довідку і побудує вектори сам — це кілька годин.
