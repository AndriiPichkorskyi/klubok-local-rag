# local-tool-rag-assistant

Локальний RAG-асистент: за описом задачі природною мовою знаходить встановлену
програму на цій ОС і пояснює, як нею скористатися. Все офлайн, через Ollama.

## Карта

| Шлях                           | Що це                                                               | Мова  |
| ------------------------------ | ------------------------------------------------------------------- | ----- |
| `config/pipeline.config.json`  | ЄДИНИЙ конфіг усього проєкта                                        | —     |
| `sidecar/src/rpc/server.js`    | WebSocket-сервер, точка входу backend                               | Node  |
| `sidecar/src/bootstrap/`       | модуль 2.1: детект ОС, перевірка Ollama і моделей                   | Node  |
| `sidecar/src/platform/`        | адаптери ОС: `macos.js` робочий, `windows.js`/`linux.js` — заглушки | Node  |
| `sidecar/src/modules/indexer/` | модуль 2.2: сканування, скрапінг, чанки, вектори                    | Node  |
| `sidecar/src/modules/rag/`     | модуль 2.3: пошук, промпти, виклик LLM                              | Node  |
| `sidecar/src/services/`        | обгортки БД, Ollama, скрапера, логера                               | Node  |
| `sidecar/src/cli/`             | термінальне меню (працює й далі, для налагодження)                  | Node  |
| `src-tauri/src/sidecar.rs`     | міст до sidecar: запуск + WebSocket + події                         | Rust  |
| `src-tauri/src/system.rs`      | скріншот, запуск програми, вікно-оверлей                            | Rust  |
| `src/user/`                    | модуль 2.4.1: Spotlight-пошук                                       | React |
| `src/dev/`                     | модуль 2.4.2: панель розробника                                     | React |
| `src/walkthrough/`             | модуль 2.5: покрокова підказка поверх екрана                        | React |

Протокол Rust↔Node: **`docs/contracts/rpc.md`**. Це обов'язкове читання перед будь-якою правкою `rpc/` або `src-tauri/`.

## Правила

1. **Бібліотека замість власного коду.** Якщо задачу закриває npm/crate — став залежність.
   Ручні реалізації пошуку, парсингу, чанкінгу відхиляються на рев'ю.
2. **Коментарі та логи — українською.** Код і назви змінних — англійською.
3. **Rust тримаємо мінімальним** (ціль: < 400 рядків). Уся логіка живе в Node.
4. **Не пиши документацію без запиту.** Знайшов баг чи ідею — рядок у `docs/improvements.md`, і далі по задачі.
5. **Не рефактори під час порту.** Спершу однакова поведінка, покращення — потім.
6. Sidecar не має знати про Tauri: він мусить запускатися окремо командою `npm run sidecar:dev`.

## Команди

```bash
npm run sidecar:install   # залежності backend
npm run sidecar:dev       # backend окремо, з автоперезапуском (--watch)
npm run sidecar:cli       # старе термінальне меню
npm run app               # застосунок, sidecar запускає Tauri
npm run app:external      # застосунок, sidecar запускаєш ти сам
```
